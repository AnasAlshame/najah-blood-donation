# An-Najah National University - Blood Donation Platform
# منصة التبرع بالدم - جامعة النجاح الوطنية

منصة متكاملة واحترافية لتسجيل وإدارة متبرعي الدم من طلبة جامعة النجاح الوطنية وتسهيل وصول الإدارة الطبية للمتبرعين حسب فصائل الدم والتوافق الحيوي.

## 🌟 الميزات الرئيسية (Key Features)

1. **تسجيل متبرع جديد (Donor Registration):**
   - واجهة سلسة وبسيطة ومتجاوبة ومصممة بألوان جامعة النجاح الوطنية الرسمية والأحمر الطبي.
   - التحقق من البيانات (الرقم الجامعي، البريد الإلكتروني، رقم الهاتف، الكلية، المدينة، فصيلة الدم، وتاريخ آخر تبرع).
   - أسئلة فحص طبي أولي مبسطة للتأكد من ملاءمة التبرع.
   
2. **محرك التوافق الحيوي لفصائل الدم (Blood Compatibility Engine):**
   - إمكانية البحث عن فصائل الدم المطابقة أو جميع الفصائل المتوافقة طبياً التي يمكنها التبرع للمريض.
   
3. **لوحة تحكم الإدارة (Admin Dashboard):**
   - تسجيل دخول آمن ومحمي بنظام JWT وتشفير كلمات المرور بـ bcrypt.
   - فلترة متقدمة حسب الفصيلة، الكلية، المدينة، وحالة المتبرع.
   - عرض البيانات بالترتيب الزمني (الأقدم في الأعلى لتنظيم دور التبرع).
   - التواصل المباشر مع المتبرع بنقرة واحدة (واتساب / اتصال).
   - تصدير بيانات المتبرعين إلى Excel / CSV.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS, Lucide Icons
- **Backend:** Node.js, Express, TypeScript, Mongoose
- **Database:** MongoDB
- **Security:** JWT Authentication, Bcrypt Password Hashing, CORS, Helmet
